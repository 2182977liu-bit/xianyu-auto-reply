# 闲鱼自动回复机器人（xianyu-auto-reply）

> 面向闲鱼个人卖家的自动回复客服机器人。通过 CDP 协议控制「闲鱼卖家客服」桌面客户端，轮询买家新消息并自动回复，支持规则库、多厂商 AI 大模型、商品知识库、网盘自动发货与半自动审核。

⚙️ 全本地运行 · 🧩 规则 + AI 双引擎 · 📦 自动发货 · 🔍 半自动审核 · ☁️ 配置热重载

---

## 功能特性

| 能力 | 说明 |
|------|------|
| ⚡ 两段式消息处理 | 先用会话列表预览快速判定（黑名单 / 系统卡片 / 冷却 / 规则命中 → 无需点开会话），只有需要 AI 的消息才点开读取上下文，减少对界面的打扰 |
| 🚦 并行 AI 生成 | 多个会话同时来消息时，AI 调用使用线程池并行（最多 3 路），等待时间重叠，总处理时间大幅缩短 |
| 🤖 三模式回复 | `rule` 纯规则 / `mixed` 规则优先 + AI 兜底 / `ai` 纯 AI；支持豆包、DeepSeek、通义千问、Kimi、智谱、讯飞等国产大模型（OpenAI 兼容接口） |
| 🧠 商品知识库 | 按商品标题关键词匹配专属须知并注入 AI 上下文，未命中走默认须知；发货 / 售后政策严格遵循、不擅自承诺退款补偿 |
| 📦 网盘自动发货 | 空闲时巡检各买家「待发货」订单，命中发货资源库自动发送网盘链接 + 提取码，订单指纹防重复 |
| 🧲 买家策略 | 黑名单不回复；单人模式覆盖 `skip / rule / mixed / ai` |
| 🚦 半自动审核 | 开启后 AI 回复先进入待确认队列，网页上确认后才发送，避免误回复 |
| 🛡️ 风控抑制 | 同会话冷却、忽略词表（确认/感谢短消息不回）、消息指纹去重、系统卡片过滤、自身消息不回复 |
| 🖥️ 可视化配置中心 | Flask Web 界面，Tab 化管理：运行面板 / AI 配置 / 规则中心 / 知识库 & 发货；支持迷你状态灯、待审核角标、规则拖拽排序、Ctrl+S 快捷保存 |
| 📈 回复审计台账 | 每次回复写入 `reply_log.jsonl`，网页端查看历史、统计今日回复 / AI 生成 / 规则命中 |
| ♻️ 配置热重载 | 网页 / MCP 修改配置后机器人几秒内自动生效，无需重启 |
| 🔌 MCP 服务 | 可安装到 TRAE / Cursor / Claude Desktop，通过对话启停机器人、改配置、扫描会话、定向发送 |

## 工作原理

```
闲鱼卖家客服（Electron 桌面软件）
        │  通过 CDP 调试协议连接（本机 9222 端口）
        ▼
bot.py 每 2 秒轮询会话列表
        │
        ├─ ① 检测：会话最后消息是否变化
        ├─ ② 预览判定：黑名单/系统卡片/冷却/规则命中 → 多数消息无需点开
        ├─ ③ 点开复核：AI 消息读取历史 + 关联宝贝 + 专属知识库
        ├─ ④ 生成：规则库 或 AI（多路并行）
        └─ ⑤ 发送：聚焦输入框 → 填入 → 校验 → 点击发送
```

自动发货链路：空闲时轮转各会话 → 点开「待发货」订单页 → 订单文本命中发货资源库 → 自动发送网盘资源（不经过 AI）。

## 快速开始

### 环境要求

- Windows 10+，Python 3.9+
- 已安装「闲鱼卖家客服」桌面客户端
- 可访问 AI API 的网络（未配 Key 时自动降级为规则 + 兜底话术）

### 安装

```bash
git clone https://github.com/2182977liu-bit/xianyu-auto-reply.git
cd xianyu-auto-reply
# （可选）创建独立虚拟环境后安装依赖
pip install -r requirements.txt
```

### 三步启动

```bash
# 1. 配置：复制模板并填入你的 AI API Key
#    复制 config.example.json 为 config.json，修改 ai.api_key / model

# 2. 以调试模式启动闲鱼卖家客服（若 9222 端口已可用可跳过）
start_xianyu_debug.bat

# 3. 试运行（只检测不回发，安全）
start_bot.bat
# 正式自动回复
start_bot.bat --no-dry-run
# 或指定模式
start_bot.bat --no-dry-run --mode ai
```

**推荐方式**：双击 `start_config.bat` 打开配置中心（http://127.0.0.1:5000），在「运行面板」一键启动 / 停止机器人，并在网页中完成全部配置。

## 配置说明

### 三种回复模式（`config.json → mode`）

| 模式 | 行为 | 适用 |
|------|------|------|
| `rule` 纯规则 | 只按关键词规则库回复，零成本 | 回复需求固定（在吗 / 多少钱 / 包邮） |
| `mixed` 规则优先 + AI 兜底（默认） | 规则命中用规则话术，未命中交 AI，AI 不可用退回兜底 | 兼顾稳定与自然 |
| `ai` 纯 AI | 所有买家消息由 AI 生成 | 聊天内容不固定 |

### 商品知识库（`product_kb`）

```
{ "match": "示例商品关键词", "info": "该商品的专属须知：发货方式、售后政策、在线时间等。" }
{ "match": "",              "info": "默认须知：...（所有未命中商品的兜底）" }
```

机器人点开会话时读取「当前宝贝」标题，命中关键词即用对应须知注入 AI 上下文。

### 网盘自动发货（`delivery_kb`）

```
{ "match": "示例商品关键词", "content": "链接：https://example.com/xxx  提取码：0000" }
```

### 买家策略（`buyers.json`) 

- `blacklist`：名单内买家一律不自动回复
- `overrides`：单人覆盖，如 `"难缠买家": "rule"`、`"同行小号": "skip"`

规则的增删改可以在配置中心完成，保存后自动热重载。

## 项目结构

```
xianyu-bot/
├── bot.py                # 机器人主程序（轮询 / 判定 / 并行生成 / 发送）
├── cdp_client.py         # CDP 控制层（连接 / 读页面 / 模拟操作）
├── ai_client.py          # 大模型调用（OpenAI 兼容，多厂商）
├── mcp_server.py         # MCP 服务器（供 AI 客户端调用）
├── config.example.json   # 配置模板（填入 Key 后复制为 config.json）
├── rules.json            # 回复规则库、忽略词表、兜底话术
├── buyers.json           # 买家策略（黑名单 / 单人覆盖）
├── config_ui/            # 可视化配置中心（Flask）
│   ├── app.py
│   └── templates/index.html
├── start_bot.bat         # 机器人启动脚本
├── start_config.bat      # 配置中心启动脚本
├── start_xianyu_debug.bat# 闲鱼客服调试模式启动脚本
└── 自动回复机制说明.md     # 详细机制文档
```

> 说明：`config.json`（含真实 API Key）、`state.json`、`bot_heartbeat.json`、`reply_log.jsonl`、`pending_review.json` 等运行文件已被 `.gitignore` 排除，不入库。

## 安全与合规

- API Key 仅保存在本地 `config.json`，仓库只提供脱敏模板；网页回显 Key 自动脱敏
- 内置冷却、忽略词、指纹去重等风控抑制，降低骚扰与平台风控风险
- 本工具仅用于个人合法经营场景的辅助回复；请遵守闲鱼平台规则与相关法律法规，勿用于刷单、导流外链等违规行为
